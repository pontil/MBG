# Monitoring MBG – Kejaksaan Negeri Muna

Website monitoring **Program Makanan Bergizi Gratis (MBG)** Kejaksaan Negeri Muna — transparansi, pengawasan, dan pelayanan aduan masyarakat.

## 🚀 Deploy ke Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/monitoring-mbg-kejari-muna)

### Langkah Manual

1. **Upload ke GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Monitoring MBG website"
   git remote add origin https://github.com/YOUR_USERNAME/monitoring-mbg-kejari-muna.git
   git push -u origin main
   ```

2. **Deploy ke Vercel**
   - Buka [vercel.com](https://vercel.com)
   - Klik **Add New → Project**
   - Import repository ini dari GitHub
   - Klik **Deploy** (tanpa konfigurasi tambahan — sudah ada `vercel.json`)
